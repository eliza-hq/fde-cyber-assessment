# Cyber FDE assessment

Language for the application security assessment and its evaluation.

## Language

**Candidate package**:
The materials a candidate receives to complete the assessment.

**Target**:
The disposable application environment a candidate is authorized to assess.

**Interviewer package**:
The private materials used to evaluate a candidate's assessment and presentation.

**Dry run**:
An internal rehearsal of the assessment using the candidate's materials and workflow.
